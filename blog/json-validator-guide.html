لماذا يرفض النظام ملف JSON الخاص بك رغم أنه يبدو صحيحًا

الملف بيبان مرتب ومقروء تمامًا، لكن النظام بيرفضه برسالة خطأ غامضة زي "Unexpected token". المشكلة غالبًا مش في الشكل، هي في تفصيلة بنيوية صغيرة مخالفة لمعيار JSON الرسمي.

محتوى المقال

  • الفرق بين "منسّق" و"صحيح بنيويًا"
  • أشهر الأخطاء الخفية اللي بتفوّت على العين
  • قواعد JSON الصارمة اللي كتير بينساها
  • كيف تتحققي من صحة JSON بسهولة؟

الفرق بين "منسّق" و"صحيح بنيويًا"

التنسيق بيرتب شكل النص بصريًا بس (مسافات، أسطر جديدة)، بينما التحقق من الصحة بيفحص إن البنية نفسها متوافقة تمامًا مع قواعد معيار JSON الرسمية. ممكن نص يكون منسّق بشكل جميل جدًا للعين، لكنه في نفس الوقت غير صحيح بنيويًا وهيترفض من أي نظام صارم.

أشهر الأخطاء الخفية اللي بتفوّت على العين

فاصلة زيادة بعد آخر عنصر في قائمة أو كائن من أشهر الأخطاء، وصعبة الاكتشاف بالعين المجردة خصوصًا في ملفات طويلة. كمان استخدام علامة اقتباس مفردة (') بدل مزدوجة (") حوالين النصوص، أو كتابة قيمة رقمية بصيغة غير مدعومة (زي أرقام بادئة بأصفار) بتسبب رفض كامل للملف.

قواعد JSON الصارمة اللي كتير بينساها

معيار JSON الرسمي بيتطلب: علامات اقتباس مزدوجة إلزامية حوالين كل مفتاح ونص (مش مفردة)، القيم المنطقية لازم تكون true أو false بحروف صغيرة بالكامل (مش True أو FALSE)، ومفيش دعم للتعليقات خالص (لا // ولا /* */) رغم إنها مقبولة في لغات برمجة كتيرة بتستوحي صيغتها من JSON.

كيف تتحققي من صحة JSON بسهولة؟

باستخدام مدقق JSON على فورا.tools:

  1. الصق بيانات JSON اللي عايزة تتأكدي من صحتها.
  2. اضغط "تحقق" — النتيجة تظهر فورًا (صحيح أو غير صحيح).
  3. لو فيه خطأ، هيتوضّح لك نوعه ومكانه بالتحديد.

أسئلة شائعة

إيه الفرق بين التنسيق والتحقق من الصحة؟

التنسيق بيرتب الشكل بصريًا بس، بينما التحقق يفحص إن البنية متوافقة مع قواعد المعيار الرسمية.

ليه أحيانًا JSON يشتغل في أداة وميشتغلش في أداة تانية؟

بعض الأدوات متسامحة أكتر مع أخطاء بسيطة، بينما أنظمة الإنتاج الصارمة بترفض أي انحراف عن المعيار.

هل القيم بـtrue أو false لازم تكون بحروف صغيرة؟

نعم، المعيار بيتطلب true وfalse وnull بحروف صغيرة بالكامل — أي صيغة تانية هتُعتبر خطأ.

هل ممكن أستخدم تعليقات داخل ملف JSON؟

لا، المعيار الرسمي مايدعمش التعليقات خالص، على عكس صيغ مشابهة زي JSON5 أو JSONC.

خلاصة

الشكل المرتب مش ضمان لصحة البيانات — التحقق البنيوي هو الفيصل الحقيقي، وأداة تحقق سريعة بتوفر عليك ساعات من البحث اليدوي عن سبب رفض نظام لملف يبدو سليم تمامًا للعين.
